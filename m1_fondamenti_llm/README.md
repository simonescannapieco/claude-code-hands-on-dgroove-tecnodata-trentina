# Modulo 1 — Fondamenti degli LLM

Le demo e l'esercitazione del primo modulo: che cosa fa un modello
linguistico, che cosa vede, dove sbaglia, e come si sceglie fra i modelli
Claude del piano Pro. Ogni elemento ha la sua cartella, con un `README.md`
che spiega che cosa fare; si comincia sempre da
`tools/prepara_esercizio.sh <ID>`, come spiega il `README.md` alla radice
del repository.

| elemento | che cosa | dove |
|---|---|---|
| M1-D01 | La prossima parola: la stessa frase, più volte, a tre modelli | demo in Claude Code |
| M1-D02 | Quante n in «interconnessione»? | demo in claude.ai, poi in Claude Code |
| M1-D03 | Stessa frase, due lingue: i token secondo Claude | demo in Claude Code |
| M1-D04 | Ogni chiamata riparte da zero | demo in Claude Code |
| M1-D05 | La circolare che non esiste | demo in claude.ai, poi in Claude Code |
| M1-E01 | Lo stesso prompt su tre modelli | esercitazione in Claude Code |

In aula le demo le esegue il docente, e le due in claude.ai le fate anche
voi, nel browser. L'esercitazione M1-E01 è il vostro primo lavoro in Claude
Code: prima, `tools/verifica_ambiente.sh` deve essere tutto verde.

Le cartelle: `s1_fondamenti_llm/` (la sessione S1), poi una cartella per
ogni parte del modulo che ha demo o esercitazioni, con il nome del
sotto-deck delle slide (`m1_3_cosa_fanno_leggono_imparano/`,
`m1_4_token_e_contesto/`, `m1_5_forze_e_limiti/`,
`m1_e2_stesso_prompt_tre_modelli/`).
