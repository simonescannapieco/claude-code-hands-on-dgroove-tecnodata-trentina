# Il generatore della rete

- Dopo una modifica a `generatore/`, rigenera dalla radice: `python3 progetti/rete/genera.py`.
- Poi i due controlli: `python3 progetti/rete/genera.py --check` e `python3 progetti/rete/genera.py --canone`.
- I file rigenerati vanno nello stesso commit della modifica al generatore.
