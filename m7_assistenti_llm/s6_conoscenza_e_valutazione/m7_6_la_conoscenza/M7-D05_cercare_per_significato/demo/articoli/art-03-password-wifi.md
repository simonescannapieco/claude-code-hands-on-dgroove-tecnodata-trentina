# Cambiare la password del Wi-Fi

La password del Wi-Fi si cambia dall'area clienti: voce «Il mio router», sezione Wi-Fi, campo Password.
Scegli una password di almeno 12 caratteri e salva: i dispositivi già collegati si scollegano.
Sui dispositivi di prima inserisci la nuova password del Wi-Fi per farli tornare in rete.
