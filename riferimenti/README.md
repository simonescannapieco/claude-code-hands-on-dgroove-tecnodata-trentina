dopo le esercitazioni. Arrivano con i moduli: quelle dei moduli già pronti
sono complete, le altre per ora hanno solo il titolo.

| [`albero-pro-vs-api.md`](albero-pro-vs-api.md) | Modulo 8 | un albero di decisione: piano Pro o API |
| [`cheat-sheet-costi.md`](cheat-sheet-costi.md) | Modulo 8 | costi e consumi in una pagina |
