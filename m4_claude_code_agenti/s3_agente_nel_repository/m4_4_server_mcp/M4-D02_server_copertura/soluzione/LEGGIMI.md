# M4-D02 — la soluzione è la registrazione del corso

Qui c'è la cartella `risposte/` della registrazione del corso del 1
novembre 2026, con Claude Code 2.1.316 e Sonnet, sull'account del docente:
lo stream-json delle sei esecuzioni della prova del docente,
`con-1.jsonl` … `senza-3.jsonl`, come le scrive `_docente/live.sh`, con
la domanda di `demo/domanda.txt`. La prova è fatta con le configurazioni
e gli stream fuori dallo spazio di lavoro fino all'ultima esecuzione (nel
README, «Perché i due bracci hanno soltanto Read, e le risposte entrano
alla fine»); le prove di prima non valgono. Gli stream non sono scritti a
mano: sono quelli della prova, con un solo cambiamento, il percorso della
cartella personale del docente scritto `~`. Non c'è `mcp/`: le
configurazioni hanno i percorsi assoluti del computer del docente.

La vostra prova (`risposta.txt` e il server configurato con
`claude mcp add`) non ha una soluzione da copiare: la verifica chiede a
Claude Code, sul vostro computer, se il server è configurato.

Copiata sopra uno spazio di lavoro nuovo, `risposte/` fa passare
`tools/verifica.sh M4-D02`.
