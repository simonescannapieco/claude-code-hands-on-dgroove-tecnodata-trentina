ottobre 2026, con Claude Code 2.1.312 e Sonnet, sull'account del
docente: la prova del docente, `_docente/live.sh --esecuzioni 3`, l'unica

copia e senza `__pycache__/`. Gli stream non sono scritti a mano: sono
