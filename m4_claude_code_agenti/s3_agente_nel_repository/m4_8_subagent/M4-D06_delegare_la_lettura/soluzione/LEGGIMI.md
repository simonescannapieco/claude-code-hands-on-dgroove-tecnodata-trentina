# Soluzione di M4-D06

Qui c'è la registrazione del corso del 28 ottobre 2026, con Claude Code
2.1.312 e Sonnet, sull'account del docente: gli stream delle tre coppie,
in `risposte/` (`delega-<n>.jsonl` e `senza-<n>.jsonl`), da cui
`tools/verifica.sh M4-D06` stampa i dati e i verdetti. È la terza prova
del docente, la prima con `--tools Agent,Read,Grep,Glob`, senza Bash
(nel README, «Perché le sessioni non hanno Bash»); le due di prima non
valgono. Gli stream non sono scritti a mano: sono quelli della prova, con
un solo cambiamento, il percorso della cartella personale del docente
scritto `~`. Copiata sopra uno spazio di lavoro nuovo, `risposte/` fa
passare `tools/verifica.sh M4-D06`.
