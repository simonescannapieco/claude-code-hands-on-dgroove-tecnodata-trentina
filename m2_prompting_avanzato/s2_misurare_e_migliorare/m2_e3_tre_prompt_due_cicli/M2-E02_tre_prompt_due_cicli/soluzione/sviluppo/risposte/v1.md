**Difetti rispetto alla convenzione 5.3** (giorni del mese reali, non 30 fissi):

- **Mese commerciale fisso a 30**: la convenzione richiede i giorni effettivi del mese. Febbraio (28 gg), canone 3000, attivazione il 15: giorni di servizio 14, rateo corretto = 3000×14÷28 = 1500; il codice dà 3000×(30−15+1=16)÷30 = 1600.
- **Mese di 31 giorni, canone pieno**: con 31 gg e nessun rateo il codice dà 3000×30÷30 = 3000, corretto. Ma con attivazione il giorno 1 si ha gg = 30 e non 31: 3000×30÷30 = 3000, mentre il giorno 1 di un mese di 31 gg dà 31/31 = 3000. Il problema emerge con la cessazione: cessata il 31 con canone 3100, il codice usa gg=31 e calcola 3100×31÷30 = 3203 (superiore al canone pieno).
- **Attivazione e cessazione nello stesso mese**: la seconda condizione sovrascrive `$gg`, ignorando il giorno di attivazione. Attivata il 10 e cessata il 20 (mese di 30 gg, canone 3000): corretto 11 gg → 1100; il codice dà 20 gg → 2000.
- **Arrotondamento**: `intdiv` tronca. Canone 1000, 30 gg del mese, 1 giorno: 33,33 → 33 va bene, ma con 2 gg su 28, 1000×2÷28 = 71,43 → 71; con 1999×1÷30 = 66,63 il codice dà 66 invece di 67. La convenzione non specifica l'arrotondamento: da confermare col team (qui uso `round`).

**Correzione**

```php
$canone  = (int)$l['canone_cent'];
$gg_mese = (int)date('t', strtotime($periodo . '-01'));
$primo   = 1;
$ultimo  = $gg_mese;
$tipo    = 'canone';
$descr   = $l['nome_offerta'] . ' - canone ' . $MESI[(int)$mese] . ' ' . $anno;

if ($l['attiva_dal'] != '' && substr($l['attiva_dal'], 0, 7) == $periodo) {
    $primo = (int)substr($l['attiva_dal'], 8, 2);
    $tipo  = 'rateo';
}
if ($l['cessata_il'] != '' && substr($l['cessata_il'], 0, 7) == $periodo) {
    $ultimo = (int)substr($l['cessata_il'], 8, 2);
    $tipo   = 'rateo';
}
$gg = max(0, $ultimo - $primo + 1);

if ($tipo == 'rateo') {
    $da = $l['attiva_dal'] != '' && substr($l['attiva_dal'], 0, 7) == $periodo
        ? 'dal ' . data_it($l['attiva_dal']) : '';
    $a  = $l['cessata_il'] != '' && substr($l['cessata_il'], 0, 7) == $periodo
        ? 'fino al ' . data_it($l['cessata_il']) : '';
    $descr = $l['nome_offerta'] . ' - canone ' . trim($da . ' ' . $a) . ' (' . $gg . ' gg)';
}
$importo = (int)round($canone * $gg / $gg_mese);
```

Nota: la correzione presuppone che `$periodo` sia nel formato `AAAA-MM`, come nel codice originale.
