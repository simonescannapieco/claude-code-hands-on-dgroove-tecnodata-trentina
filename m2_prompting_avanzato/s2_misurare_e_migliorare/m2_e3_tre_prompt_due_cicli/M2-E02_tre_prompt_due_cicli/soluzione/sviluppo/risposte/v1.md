**Cosa fa**: calcola l'importo (in centesimi) del canone mensile di una linea su base commerciale a 30 giorni. Se la linea è attivata nel mese, fa il rateo dal giorno di attivazione; se è cessata nel mese, il rateo fino al giorno di cessazione. `intdiv` tronca il risultato.

**Difetti**

- **Attivata e cessata nello stesso mese**: il secondo `if` sovrascrive il primo, quindi si ignora la data di attivazione. Esempio: canone 3000, attiva il 10, cessata il 20 → dovrebbe essere 11 gg = 1100, il codice dà 20 gg = 2000.
- **Giorno 31**: con mese commerciale a 30, `gg_mese - g + 1` diventa 0 o negativo. Esempio: attiva il 31, canone 3000 → gg = 0, importo 0 (dovrebbe essere almeno 1 gg = 100). Con cessazione il 31, gg = 31 → 3100, più del canone pieno.
- **Febbraio**: cessata il 28 febbraio è fatturata 28/30 anziché il mese intero. Esempio: canone 3000 → 2800 invece di 3000.
- **Troncamento**: `intdiv` perde il resto. Esempio: canone 1000, 7 gg → 7000/30 = 233,33 → 233 (arrotondato, 233 è corretto qui), ma con canone 1010 e 20 gg → 673,33 → 673; con 1015 e 20 gg → 676,67 → 676 invece di 677.

**Correzione**

```php
$gg_mese = 30;
$ini = 1;
$fin = $gg_mese;

if ($l['attiva_dal'] != '' && substr($l['attiva_dal'], 0, 7) == $periodo) {
    $ini = min((int)substr($l['attiva_dal'], 8, 2), $gg_mese);
}
if ($l['cessata_il'] != '' && substr($l['cessata_il'], 0, 7) == $periodo) {
    $fin = min((int)substr($l['cessata_il'], 8, 2), $gg_mese);
}

$gg = max(0, $fin - $ini + 1);
$importo = intdiv($canone * $gg * 2 + $gg_mese, $gg_mese * 2); // arrotondamento al centesimo

if ($ini > 1 || $fin < $gg_mese) {
    $tipo = 'rateo';
}
```

Per il caso febbraio, se la cessazione cade nell'ultimo giorno del mese, va posto `$fin = $gg_mese`. Le descrizioni vanno composte dopo il calcolo, con `$ini`, `$fin` e `$gg`.
