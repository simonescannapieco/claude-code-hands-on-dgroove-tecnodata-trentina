**Funzione:** calcola il canone mensile di una linea con mese commerciale di 30 giorni. Se la linea è attivata o cessata nel mese, applica un rateo `canone * gg / 30`.

**Difetti**
- **Attivazione e cessazione nello stesso mese:** il secondo `if` sovrascrive `gg`. Con canone 3000, attiva il 10 e cessata il 20, dovrebbero essere 11 gg (1100) e invece si calcolano 20 gg (2000).
- **Cessazione il giorno 31:** `gg = 31`, quindi l'importo supera il canone. Con canone 3000 si addebitano 3100.
- **Attivazione il giorno 31:** `gg = 30 - 31 + 1 = 0`, quindi importo 0 invece di 1 giorno (100).
- **Cessazione a fine febbraio:** il 28/02 dà `gg = 28`, cioè 2800 su 3000, mentre il mese è completo e andrebbe addebitato per intero.
- **Arrotondamento:** `intdiv` tronca sempre. Con canone 1999 e 1 gg si ottiene 66 invece di 67 (66,63), quindi si perde fino a 1 cent per riga.

**Correzione**
```php
$canone = (int)$l['canone_cent'];
$gg_mese = 30;
$ultimo = (int)date('t', strtotime($periodo . '-01'));
$da = 1;
$a = $gg_mese;
$tipo = 'canone';
$descr = $l['nome_offerta'] . ' - canone ' . $MESI[(int)$mese] . ' ' . $anno;

if ($l['attiva_dal'] != '' && substr($l['attiva_dal'], 0, 7) == $periodo) {
    $da = min((int)substr($l['attiva_dal'], 8, 2), $gg_mese);
}
if ($l['cessata_il'] != '' && substr($l['cessata_il'], 0, 7) == $periodo) {
    $g = (int)substr($l['cessata_il'], 8, 2);
    $a = ($g >= $ultimo) ? $gg_mese : min($g, $gg_mese);
}

$gg = max(0, $a - $da + 1);

if ($da > 1 || $a < $gg_mese) {
    $tipo = 'rateo';
    $descr = $l['nome_offerta'] . ' - canone';
    if ($da > 1) $descr .= ' dal ' . data_it($l['attiva_dal']);
    if ($a < $gg_mese) $descr .= ' fino al ' . data_it($l['cessata_il']);
    $descr .= ' (' . $gg . ' gg)';
}

// arrotondamento al centesimo più vicino
$importo = intdiv($canone * $gg * 2 + $gg_mese, 2 * $gg_mese);
```
