- **Mese fisso a 30 giorni**: la convenzione 5.3 divide per i giorni reali del mese. Attivazione il 15 febbraio 2026 (28 gg), canone 2800: corretto 2800×14÷28 = 1400; il codice dà 2800×16÷30 = 1493.
- **Mese di 31 giorni, attivazione il 1°**: gg = 30 − 1 + 1 = 30, quindi tipo "rateo" con 30/30. Canone 3100, luglio: corretto 3100 (31/31); il codice dà 3100×30÷30 = 3100 solo per caso, ma attivando il 31 gg = 0 invece di 1: corretto 3100×1÷31 = 100; il codice dà 3100×0÷30 = 0.
- **Mese di 31 giorni, cessazione a fine mese**: cessazione il 31 luglio, canone 3100: corretto 3100; il codice dà 3100×31÷30 = 3203 (oltre il canone pieno).
- **Attivata e cessata nello stesso mese**: la seconda condizione sovrascrive la prima e conta dal 1°. Attiva il 10, cessata il 20, canone 3000 (30 gg): corretto 3000×11÷30 = 1100; il codice dà 3000×20÷30 = 2000.
- **Troncamento con `intdiv`**: arrotonda sempre per difetto. Canone 1000, 3 gg su 28: esatto 107,14 → 107 va bene, ma con 2800×1÷28... è esatto; con 1999×1÷28 = 71,39 va bene; con 1000×15÷28 = 535,71 il codice dà 535 invece di 536 (arrotondamento commerciale).

Correzione:

```php
$gg_mese = (int)date('t', mktime(0, 0, 0, (int)$mese, 1, (int)$anno));
$gg = $gg_mese;

// attivata nel mese
$gg_inizio = 1;
if ($l['attiva_dal'] != '' && substr($l['attiva_dal'], 0, 7) == $periodo) {
    $gg_inizio = (int)substr($l['attiva_dal'], 8, 2);
    $tipo = 'rateo';
}
// cessata nel mese
$gg_fine = $gg_mese;
if ($l['cessata_il'] != '' && substr($l['cessata_il'], 0, 7) == $periodo) {
    $gg_fine = (int)substr($l['cessata_il'], 8, 2);
    $tipo = 'rateo';
}
$gg = $gg_fine - $gg_inizio + 1;
// (la descrizione va adattata con $gg_inizio/$gg_fine)
$importo = intdiv($canone * $gg * 2 + $gg_mese, $gg_mese * 2);
```

Nota: il secondo punto sopra è debole (l'esempio con attivazione il 31 dà in realtà gg = 0 solo nei mesi da 30 giorni non esiste); il difetto reale è nei mesi da 31 giorni, dove gg = 30 − 31 + 1 = 0 invece di 1.
