- **Mese fisso a 30 giorni** (la 5.3 vuole i giorni reali del mese).
  - Ottobre (31 gg), canone 3100, attivata il 1°: il codice dà 30 gg e quindi 3000, mentre il giusto è 3100.
  - Febbraio (28 gg), canone 2800, attivata il 15: il codice dà 2800×16÷30 = 1493, mentre il giusto è 2800×14÷28 = 1400.
- **Attivazione il 31**: `gg = 30 - 31 + 1 = 0`, quindi importo 0. Con canone 3100 il giusto è 3100×1÷31 = 100.
- **Cessazione il 31 di un mese da 31 gg**: `gg = 31` su base 30, quindi si fattura più del canone. Con canone 3000 il codice dà 3100, mentre il giusto è 3000.
- **Attivazione e cessazione nello stesso mese**: il secondo `if` sovrascrive il primo e ignora il giorno di attivazione. Con attivazione il 10, cessazione il 20, mese di 30 gg e canone 3000, il codice dà 20 gg e quindi 2000, mentre il giusto è 11 gg e quindi 1100.

Correzione (assumo, come fa il codice, che il giorno di cessazione sia incluso):

```php
$canone  = (int)$l['canone_cent'];
$gg_mese = cal_days_in_month(CAL_GREGORIAN, (int)$mese, (int)$anno);
$dal     = 1;
$al      = $gg_mese;
$tipo    = 'canone';
$descr   = $l['nome_offerta'] . ' - canone ' . $MESI[(int)$mese] . ' ' . $anno;

if ($l['attiva_dal'] != '' && substr($l['attiva_dal'], 0, 7) == $periodo) {
    $dal  = (int)substr($l['attiva_dal'], 8, 2);
    $tipo = 'rateo';
}
if ($l['cessata_il'] != '' && substr($l['cessata_il'], 0, 7) == $periodo) {
    $al   = (int)substr($l['cessata_il'], 8, 2);
    $tipo = 'rateo';
}
$gg = max(0, $al - $dal + 1);

if ($tipo == 'rateo') {
    $descr = $l['nome_offerta'] . ' - canone'
        . ($dal > 1 ? ' dal ' . data_it($l['attiva_dal']) : '')
        . ($al < $gg_mese ? ' fino al ' . data_it($l['cessata_il']) : '')
        . ' (' . $gg . ' gg)';
}
$importo = intdiv($canone * $gg, $gg_mese);
```
