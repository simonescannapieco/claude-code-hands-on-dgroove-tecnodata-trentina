# Registro delle versioni

Una riga per ogni versione misurata: la pratica che la versione mette alla
prova, una sola (l'elenco: `./misura.sh --pratiche`; v0 è la «partenza»),
che cosa avete cambiato rispetto alla versione prima, e che cosa è
successo (i totali della riga «totali» di `./misura.sh --confronta`).
Scrivete la pratica prima di misurare la versione: `--confronta` la legge
qui. Al posto dei «…» scrivete voi.

| versione | pratica | che cosa ho cambiato | controlli | giudice | note |
|---|---|---|---|---|---|
| v0 | partenza | il prompt di partenza | … | … | … |
| v1 | … | … | … | … | … |
| v2 | … | … | … | … | … |
